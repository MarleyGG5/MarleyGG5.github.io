# marleygg5-personal-website

Personal portfolio website for **Marley Gladman-Grace** — Computer Science (BSc) student at Bath Spa University.

A lightweight, fully static site (HTML, CSS and vanilla JavaScript — no build step or backend) with sections for about, education, experience, projects, technical skills, certifications & achievements, and contact.

## Viewing the site

Open `index.html` directly in a browser, or serve the folder locally:

```sh
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Structure

- `index.html` — single-page site markup
- `css/style.css` — theme, layout, responsive rules and animations
- `js/main.js` — mobile navigation, scrollspy, reveal-on-scroll and footer year
